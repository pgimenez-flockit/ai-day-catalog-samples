# Catálogo de ejemplo: entradas anonimizadas

Este repositorio contiene entradas de muestra para la demostración del catálogo interno.

- Cada carpeta simula un proyecto y contiene únicamente un archivo `catalog-info.yaml`.
- No incluye código fuente.
- Los nombres, coordenadas y descripciones son genéricos y fueron anonimizados. Se conservan los datos técnicos reales (tipo de proyecto, versiones de Java y Spring Boot) y el dominio funcional general.
- El catálogo ingiere estos archivos siguiendo el enfoque de "catálogo como código".
